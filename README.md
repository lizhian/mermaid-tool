# Mermaid 图表编辑器 (Mermaid Editor)
这是一个基于 Web 的单文件 Mermaid 图表编辑器，支持实时预览、本地存储、S3 云端同步和多标签页管理。无需构建，开箱即用。
## ✨ 主要功能
*   **实时预览**: 左侧编辑代码，右侧实时渲染 Mermaid 图表。
*   **多图表管理 (Tabs)**: 支持多标签页，同时编辑多个图表。支持拖拽排序。
*   **双击重命名**: 双击标签页名称即可直接修改图表名称。
*   **本地存储**: 使用 IndexedDB 自动保存您的工作，刷新页面不丢失数据。
*   **云端同步 (S3)**:
    *   支持配置兼容 S3 的对象存储 (AWS S3, MinIO, Cloudflare R2 等)。
    *   **云端文件列表**: 浏览、创建文件夹、重命名、删除云端文件。
    *   **版本控制**: 每次保存自动生成备份，支持查看历史版本、版本对比 (Diff) 和一键回退。
    *   **自动保存**: 支持自定义空闲时间自动保存到云端，并显示倒计时。
*   **缩放与拖拽**: 支持对预览区域的图表进行无限缩放和平移。
*   **导出功能**: 支持将图表导出为 PNG, JPG, SVG 格式，或复制到剪贴板。
*   **无依赖构建**: 单个 HTML 文件，依赖通过 CDN 加载，无需 Node.js 环境，双击即可运行。
## 🚀 使用方式
### 1. 启动
*   **直接运行**: 下载 `index.html` 文件，使用 Chrome, Edge 或 Firefox 等现代浏览器直接打开。
*   **本地服务 (可选)**: 如果需要更严格的跨域测试，可以使用 Python 启动本地服务器：
    ```bash
    python3 -m http.server 8000
    ```
    然后访问 `http://localhost:8000`。
### 2. 配置 S3 云存储 (可选)
点击底部的 **"设置"** 按钮，在弹出的窗口中配置您的 S3 信息：
*   **Endpoint**: S3 API 地址 (例如 `https://s3.amazonaws.com` 或您的私有云地址)。
*   **Region**: 区域代码 (例如 `us-east-1`)。
*   **Access Key ID** & **Secret Access Key**: 您的访问密钥。
*   **Bucket Name**: 存储桶名称。
*   **备份策略**: 设置最大保留的历史版本数量。
*   **自动保存**: 开启后，当您停止输入一段时间（默认 1 分钟）后，系统会自动保存并备份文件。
> **注意**: 密钥仅保存在您浏览器的 LocalStorage 中，不会发送给任何第三方服务器。
### 3. 文件操作
*   **新建/保存**: 默认处于“本地模式”。点击“保存到云端”可将当前工作区上传。
*   **打开文件**: 点击“打开”按钮，浏览云端文件列表。
*   **版本回退**: 加载云端文件后，底部会出现“回退”按钮，点击可查看历史版本列表，并与当前版本进行代码对比。
### 4. 快捷键
*   `Ctrl + S` / `Cmd + S`: 保存
*   `Ctrl + +` / `Cmd + +`: 放大预览
*   `Ctrl + -` / `Cmd + -`: 缩小预览
*   `Ctrl + 0` / `Cmd + 0`: 重置缩放
## 🛠️ 技术栈
*   **HTML5 / CSS3 / JavaScript (ES6+)**
*   **Tailwind CSS** (样式)
*   **Mermaid.js** (图表渲染)
*   **AWS SDK for JavaScript** (S3 交互)
*   **jsDiff** (文本对比)
*   **html2canvas** (图片导出)
*   **FontAwesome** (图标)
